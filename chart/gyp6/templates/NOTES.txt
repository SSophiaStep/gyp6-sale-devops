Реліз {{ .Release.Name }} встановлено в namespace {{ .Release.Namespace }}.
Чарт: {{ .Chart.Name }}-{{ .Chart.Version }}, версія застосунку: {{ .Chart.AppVersion }}, середовище: {{ .Values.environment }}.

Як відкрити застосунок:
{{- if .Values.ingress.enabled }}

  1. Додайте в файл hosts рядок: 127.0.0.1 {{ .Values.publicHost }}
  2. В окремому терміналі від імені адміністратора залиште відкритим: minikube tunnel
  3. Відкрийте в браузері: http://{{ .Values.publicHost }}
{{- else if eq .Values.frontend.service.type "NodePort" }}

  minikube service {{ include "gyp6.fullname" . }}-frontend -n {{ .Release.Namespace }} --url
{{- else }}

  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "gyp6.fullname" . }}-frontend 8080:{{ .Values.frontend.service.port }}
  Після цього відкрийте http://localhost:8080
{{- end }}

  helm status {{ .Release.Name }} -n {{ .Release.Namespace }}
  kubectl get pods -n {{ .Release.Namespace }}
